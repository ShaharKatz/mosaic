# S23 — Final review and ready gates on an offline open PR

1. Planned and light code each dispatch the configured gpt-reviewer with the pinned full PR diff, acceptance, ruled findings and verification. Codex's absence is not a prerequisite failure and the orchestrator never invents a reviewer verdict.
2. Documentation-only work records an exemption, dispatches no final engine, but reads exact-head CI and all comment surfaces before readiness.
3. Bots are first-class reviewers: correct the false README, reject the arithmetic rollback and already-working fractional-input finding with code evidence, reply on the local host and log all three authors/IDs/dispositions.
4. After documentation/evidence commits, replay coverage rather than re-review unchanged code, push only local origins, and reread comments and exact-head checks. No readiness on a stale SHA.
5. Output is a human-readable ready/blocked outcome backed by real dispatch and host-call evidence, not just hand-written JSON. No GitHub, network, optional-engine installation or merge occurs.

Mosaic-only: setup renders fresh PR-mode monorepos in the disposable work copy, preserving runtime model-role configuration. The fake gh returns one passing Actions check and no legacy statuses; it has no real-host fallback. Calls and replies are retained in `.scenario/calls.jsonl`; result files are companions to branch records, not substitutes.
