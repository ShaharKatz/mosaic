# PR evidence
Pull requests touching the scoped paths carry human-readable evidence, real outputs and explicit limits. Browser checks and pictures need the human's OK; otherwise say not verified visually. Missing evidence alone is procedural (P); an observed wrong state or false/unsupported claim is substantive (S).
Canonical rule: `docs/standards/pr-evidence.md`.
